# Glass Home

Glass Home 是一款本地优先的浏览器新标签页扩展，将常用网站、时间、搜索、日历与待办整合在统一的可自定义网格中。所有设置与内容均保存在当前浏览器本地，无需账号，不进行行为统计，也不依赖远程脚本或云服务。

## 功能特性

### 主屏幕

- 提供时钟、日期、月历、搜索与常用网站入口。
- 首次使用附带 20 个预设快捷方式，可随时添加、编辑、复制或删除。
- 快捷方式支持自定义名称、网址、图标文字、图标颜色与打开方式；浏览器已缓存站点图标时会自动显示真实图标。
- 提供时钟、搜索、日历、待办四种小组件。每种小组件在同一主屏幕中保留一个实例，移除时会一并清除该组件保存的内容。

### 布局与编辑

- 为宽、中、窄三种屏幕分别保存独立的网格布局。
- 支持拖动调整位置，包括移动、交换与插入排列，并可一键紧凑整理。
- 选中网格对象后，可用方向键移动，使用 `Alt + 方向键` 调整尺寸。
- 支持 `Ctrl/Cmd + Z` 撤销、`Ctrl/Cmd + Shift + Z` 重做，以及通过 `Esc` 取消尚未保存的布局预览。

### 个性化设置

- 外观：跟随系统、浅色或深色主题；四档材质效果；减少动态效果。
- 壁纸：三款内置渐变，或使用本地图片作为自定义壁纸（最大 4MB），并可调整背景模糊与明暗遮罩。
- 搜索：支持 Google、Bing、百度、DuckDuckGo 及自定义搜索模板，可选择在新标签页或当前标签页中打开结果。
- 时间与日历：支持 12/24 小时制、时区、秒、日期与星期显示设置；日历固定显示完整月历，并可设置每周起始日。

### 数据管理

- 设置、布局、快捷方式、自定义壁纸与小组件数据均保存在当前浏览器中。
- “设置 → 数据”提供备份导出与导入、按小组件清除数据、恢复默认主屏幕及清除全部数据。
- 数据读取异常时，可导出原始数据、导入备份或重建默认主屏幕。
- 备份文件为明文 JSON，包含快捷方式与待办等个人内容，请妥善保管。

## 安装与使用

### 环境要求

- Node.js 22 或更高版本
- pnpm

### 本地构建

```bash
pnpm install
pnpm build
```

构建产物位于 `.output/chrome-mv3`。

### 加载到浏览器

1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载解压缩的扩展”。
4. 选择 `.output/chrome-mv3` 目录。
5. 打开新标签页即可使用 Glass Home。

如需生成可分发的压缩包，请运行：

```bash
pnpm zip
```

生成的安装包为 `glass-home-1.0.0-chrome.zip`。

## 隐私与权限

Glass Home 仅申请 `favicon` 权限，用于读取浏览器已经缓存的站点图标；未声明主机权限，不读取浏览历史、书签、剪贴板或网站内容。扩展自身不发起后台网络请求；提交搜索时，由浏览器导航至用户选择的搜索引擎。

项目不提供账号、云同步或跨设备迁移，也不会收集使用数据。完整的权限、数据存储与网络行为说明见 [`docs/privacy-and-permissions.md`](docs/privacy-and-permissions.md)。

## 已知限制

- 当前为 1.0.0 正式版，仅对 Microsoft Edge 完成完整验证；Chrome、Firefox 与 Safari 尚未验证。
- 数据仅保存在当前浏览器配置文件中。清除浏览器数据、更换配置文件或卸载扩展都会导致本地数据丢失，请提前导出备份。
- 不同浏览器、不同配置文件之间的数据相互独立。
- 每种小组件仅支持一个实例，移除小组件会同时清除其本地内容。
