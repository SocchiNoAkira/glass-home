## 3. 真实 Edge 用例（13 项）

### 核心主屏幕：5 项

1. 初始化 3 个内置组件与 20 个快捷方式；10/8/5 列各有 23 个合法布局项；响应式切换与窄屏无横向溢出。
2. 新增、编辑、复制、删除快捷方式，刷新后恢复；各断点实例与布局同步。
3. 拒绝 `javascript:`；搜索与直接网址的**初始导航 URL**正确。测试暂时拦截外部导航，不依赖 Google 地区跳转、反自动化页面或服务可用性，因此这不是外部搜索引擎可用性验收。
4. 外观、材质、时区、秒显示、完整月历切换与搜索引擎持久化；刷新后设置仍在。
5. 离线刷新后快捷方式可显示；导出并导入 Workspace 备份，刷新后恢复。

### 恢复与交互：4 项

6. 完全关闭并重新启动浏览器后，恢复新增快捷方式和主题，不仅是当前页 reload。
7. 删除全部快捷方式后显示空状态；三个内置组件仍在；刷新后空状态保持。
8. 指针移动超过阈值时不误导航、不改变布局；后续普通点击仍能打开目标。
9. 注入 IndexedDB 写入故障时显示保存失败并回滚乐观更新；非法备份被拒绝且不改变原 Workspace。

### 图片、恢复与安全：3 项

10. 选择本地 PNG 壁纸，导出包含资源的备份；恢复默认后重新导入，壁纸在刷新后恢复。
11. 损坏 Workspace 进入恢复界面；可导出原始数据；可从有效备份恢复完整主屏幕。
12. 保存后立即 reload 的竞态用例通过；sandbox 父 DOM 和扩展 API 隔离；生产清单无额外权限，sandbox CSP 禁止动态执行和网络连接。

### 视觉：1 项

13. 在生产扩展中完成默认页、编辑态、设置页、浅色实体材质及窄屏截图；检查无页面异常、无非预期外部请求。

## 4. 本轮修复的关键问题

1. **测试等待与真实卸载竞态**：E2E 统一等待保存状态；`WorkspaceRepository.close()` 等待已排队写入后再释放数据库连接，并以立即 reload 用例验证。
2. **外部搜索测试不稳定**：改为捕获扩展发出的初始导航 URL，不把外部网站最终页面当扩展断言。
3. **标签定位**：时间/搜索表单补充显式 `id/htmlFor`；Edge 下使用稳定控件 ID 并单独断言可访问名称。
4. **测试级联**：各用例自行准备必要数据，不依赖前序测试留下的快捷方式。
5. **导入原子性**：先完整校验和解码资源，再以同一个 IndexedDB 事务替换 Workspace 及资源，避免半导入状态。
6. **保存成功语义**：普通提交返回真实 Promise；设置只有保存成功才关闭并更新预览，写入失败不会误报成功。
7. **恢复页缺口**：补齐原始数据导出、备份导入及明确确认后的重建入口。
8. **误触与范围**：6px 指针移动阈值只抑制意外导航，不启动布局事务；移除会误导为已有拖动能力的手柄提示。
9. **旧测试失效**：阶段 0 原型用例归档保留，默认 E2E 仅运行当前 `stage-1*.spec.ts`。
