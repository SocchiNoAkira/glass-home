## 已知环境差异与限制

- **沙箱页 CSP 语义**：`sandbox.pages` 的页面在 unique origin 下运行，`script-src 'self'` 匹配不到任何资源，脚本被**静默阻止**（标签存在、文件完整、永不执行）。已在 `wxt.config.ts` 的 `sandbox` 策略中补 `'unsafe-inline'`。其他浏览器是否同语义未验证。
- **`requestAnimationFrame` 在沙箱 iframe 内不触发**（Edge 实测：1s 内未执行）。因此沙箱的请求发送不能依赖 rAF，改用定时重试。
- Playwright 默认 locator 稳定性等待在此 Edge/扩展页组合中曾阻塞；回归先断言可见、可用、布局框，再使用原生鼠标事件。
- 原生 `dialog`（`showModal`）打开时页面其余部分 inert；测试需先等对话框关闭再操作页面。
- Google 搜索可能发生地区跳转与反自动化挑战；测试只捕获扩展的初始导航 URL，不把第三方最终页面当作通过条件。
- 页面截图通道曾不稳定；独立 Edge 测试 profile 的 CDP 截图成功。截图写入系统临时目录的 `glass-home-shots`（可被 `GLASS_HOME_SHOTS` 覆盖），不纳入版本管理。

## 发布原则

正式发布需要 **Chrome 与 Edge 两者**的真实浏览器验收（基线 14.6）、完整 P0 测试、迁移与恢复验证、安全与无障碍回归。

当前状态：**Edge 满足，Chrome 未执行**。因此跨浏览器验收**未达成**，不得将 Edge 的结果外推为 Chrome 或"Chromium 系均可用"的结论。
