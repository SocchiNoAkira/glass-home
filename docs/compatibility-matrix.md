## 已知测试环境差异

- Playwright 默认 locator 稳定性等待在当前 Edge/扩展页组合中曾阻塞；回归先断言可见、可用、布局框，再使用原生鼠标事件。
- Edge 的隐式 label 查询曾与可访问树不一致；测试使用稳定 ID，并保留 `toHaveAccessibleName` 断言。
- Google 可能发生地区跳转与反自动化挑战；测试捕获扩展初始导航 URL，不将第三方最终页面作为产品通过条件。
- 页面截图通道曾不稳定；本次独立 Edge 测试 profile 的 CDP 截图成功。聊天图片上传存在存储限制，不影响本地文件。
- 本阶段无 background worker，不能根据本矩阵推断后台休眠或跨页面同步行为。

## 发布原则

正式发布需要 Chrome 与 Edge 的真实浏览器验收、完整 P0 测试、迁移/恢复验证、安全与无障碍回归。不能以当前 MVP 或单元测试替代。
